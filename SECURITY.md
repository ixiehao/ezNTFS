# Security policy

For issues involving administrator privileges, disk mounts, or file integrity, use [GitHub private vulnerability reporting](https://github.com/ixiehao/ezNTFS/security/advisories/new). Include the ezNTFS and macOS versions, reproducible steps, and the observed impact. Redact volume identifiers, personal paths, and file contents. Use synthetic files and a disposable disk image where possible.

## 安全问题报告

涉及管理员权限、磁盘挂载或文件完整性的问题，请通过 [GitHub 私密漏洞报告](https://github.com/ixiehao/ezNTFS/security/advisories/new)提交。请附受影响的应用和 macOS 版本、复现步骤及影响，移除设备标识、个人路径和文件内容。可用临时镜像和合成文件复现。
